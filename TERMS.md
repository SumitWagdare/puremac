# Terms of Service & Privacy Policy

## 1. Local Processing
PureMac is designed to operate entirely locally on your macOS device. The application does not transmit any data, files, scan results, or system information to any external server. 

## 2. File Deletion
PureMac provides tools to permanently delete files and directories from your system (e.g., Application Support data, caches, large files).
**Warning:** By using the "Clean" or "Delete" features, you understand that these actions are irreversible. Files deleted by PureMac cannot be recovered from the Trash. You assume all responsibility for verifying the items selected for deletion.

The Software is provided "as is", without warranty of any kind. In no event shall the developer be liable for any data loss, system instability, or other damages arising from the use of PureMac.

## 4. Updates
Because PureMac operates entirely offline, it does not auto-update. New versions must be downloaded and installed manually by the user.
